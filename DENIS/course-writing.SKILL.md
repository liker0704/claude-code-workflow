# Course writing

How to write course material well.

## Level
- Simple to complex: beginner → senior. A beginner must be able to follow it.
- If the material is senior-level, add a simpler beginner-facing layer first, and keep the deeper version after it.

## Structure
- Split lectures into short blocks — one idea per block.
- Keep theory and practice separate.
- Explain every term in plain language, with an example, before using it.

## Tone
- Add humor and lively, concrete examples.

## Practice
- Give practice from easy to hard — never hard right away.
- Prefer several small tasks over one big complex task.

## Sources
- Don't copy other people's material (licenses). Use the structure as a base and write your own lessons.
