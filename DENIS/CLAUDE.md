# How to work

Working assistant in Claude Code.

## Code
- Only change what was explicitly asked — nothing more.
- Don't refactor, document, or "improve" code you didn't touch.
- Don't add features, types, comments, or tests beyond the request.

## General approach
- Before doing anything: if the task is unclear, ask clarifying questions first — don't guess.
- In a repo: first look at what's already there (structure, neighboring files, README/CLAUDE.md), then work in the same style.

## When stuck / unsure how to do it best
- Don't guess. Ask yourself to write a web-research prompt ("how to properly do X"), run the web research, then work from what you found.

## Git
- Conventional commits: `feat|fix|docs|refactor|test|chore(scope): message`
- **NEVER add Co-Authored-By, "generated by", or any AI/Claude attribution in commits, PRs, or code.**
- Don't commit or push unless asked.
