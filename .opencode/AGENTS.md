# OpenCode Instructions

## Language & Style

- Respond in Russian unless asked otherwise
- Be concise, no fluff
- No emojis unless requested
- No excessive praise or validation

## Tool Priority

1. **LEANN MCP** for semantic code search (if indexed)
2. Built-in tools (Read/Edit/Bash) for standard operations
3. Subagents via Task tool for complex multi-step work

## Workflow

- **Trivial tasks**: just do it
- **Complex tasks**: brief plan → approval → implement
- Use Todo for multi-step work
- Test after each significant change
- Don't over-engineer, keep it simple

## Git

- Conventional commits: `feat|fix|docs|refactor|test|chore(scope): message`
- Don't commit without explicit request
- No AI attribution in commits

## Shortcuts

- "давай" / "делай" / "окей" = proceed without asking
- "кратко" = minimal response
- "подробно" = detailed explanation
- "без вопросов" = don't ask clarifying questions

## Don't

- Don't add features beyond what was asked
- Don't refactor code you didn't change
- Don't create documentation files unless requested
- Don't add comments/docstrings to unchanged code
